--- How to define a map ---

1    -> 250  = [SMALL]
251  -> 500  = [MEDIUM]
501  -> 1000 = [LARGE]
1001 -> ???? = [X-LARGE]

--- What must have to be here ---

1.   Map thumbnail;
2.   Spawn points shown by colored numbers as in vanilla (resource pools are optional);
3.   Maximum size of 500×500;
4.   The TMX file must work on our end. It doesn’t need to load the tileset files, but it cannot show tile errors under any circumstances, as we use the file to check the map size;
5.   Your name to be used for credits;
6.   A custom thumbnail without spawn points must be “ready to play,” meaning you can simply select the map, choose the difficulty, and start playing without needing to configure the team spawn points.
